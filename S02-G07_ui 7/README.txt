Palm LCI Portal  เว็บต้นแบบของกลุ่ม S02-G07

หน้าเว็บมี 5 หน้า
  ภาพรวม            ห่วงโซ่การผลิต ก๊าซเรือนกระจกรายขั้นตอน และตัวเลขขอบเขตข้อมูล
  ถามจากหลักฐาน     พิมพ์คำถาม ระบบค้นข้อเท็จจริง 5 อันดับด้วยโมเดล MiniLM แล้วตอบจากหลักฐานทันที
                    กดปุ่ม ถาม Gemini เพื่อให้ Gemini เรียบเรียงคำตอบจากหลักฐานทั้งห้าอันดับ
  สถิติการผลิต       ผลผลิตและเนื้อที่ปลูกทั้งประเทศ 43 ปี จังหวัดผู้ผลิตสูงสุดแบบเล่นดูรายปี ผลผลิตรายภาค และน้ำที่ใช้รายภาค
  บัญชีรายการ       Input และ Output ของทุกกระบวนการ พร้อมแหล่งข้อมูลและผลการตรวจสอบ ดาวน์โหลด CSV ได้
  แหล่งข้อมูล        แหล่งข้อมูลทั้ง 6 แหล่ง พร้อมลิงก์เอกสาร

ข้อมูลในโฟลเดอร์ data มาจากฐานข้อมูล 5NF ของทีม ชุดเดียวกับ CSV บน GitHub
  v_lci_exchange v_exchange_status v_ghg_per_t_cpo คือผลจาก view ใน S02-G07_DDL.sql
  triples.csv คือทริปเปิล 41 แถว ชุดเดียวกับที่ใช้ใน Colab W14

วิธีรันบน Mac
  1  เปิด Terminal แล้วเข้าโฟลเดอร์นี้
       cd ที่อยู่ของโฟลเดอร์ S02-G07_ui
  2  สร้างและเปิด venv ครั้งแรกครั้งเดียว
       python3 -m venv .venv
       source .venv/bin/activate
       pip install -r requirements.txt
     ครั้งต่อไปพิมพ์แค่ source .venv/bin/activate
  3  ใส่คีย์ Gemini ใน Terminal เท่านั้น ห้ามเขียนลงไฟล์
       export GEMINI_API_KEY="วางคีย์ตรงนี้"
     ถ้าไม่ใส่คีย์ เว็บยังใช้ได้ครบ แค่ไม่มีปุ่ม ถาม Gemini
  4  รันเว็บ
       python app.py
     รอจนขึ้นว่า เปิดเบราว์เซอร์ที่ http://127.0.0.1:8080 แล้วเปิดลิงก์นั้นใน Chrome หรือ Safari
  5  ปิดเว็บ กด Control และ C ใน Terminal

ทดสอบก่อนนำเสนอ
  ในโฟลเดอร์นี้ที่เปิด venv และ export คีย์แล้ว พิมพ์
       python3 S02-G07_selftest.py
  สคริปต์จะถามคำถามตัวอย่างทั้งหมดด้วยโมเดลจริง บอกว่าข้อไหนผ่าน และลองเรียก Gemini จริง 4 ข้อ
  สคริปต์ไม่พิมพ์คีย์ออกมา

วิธีตอบในหน้า ถามจากหลักฐาน
  คำตอบจากหลักฐาน   ขึ้นทันที ไม่ใช้อินเทอร์เน็ต ถ้าคำถามถามจำนวน ระบบเลือกหลักฐานที่มีตัวเลข
                    และรวมหลักฐานที่เป็นเรื่องเดียวกัน เช่น T17 กับ T22
  ถาม Gemini        กดเมื่อต้องการ รอสูงสุด 12 วินาที ถ้าไม่ทันหรือเชื่อมต่อไม่ได้
                    คำตอบจากหลักฐานยังอยู่บนจอ และกดลองใหม่ได้
  เปลี่ยนเวลารอได้ด้วย export GEMINI_TIMEOUT_S="20" ก่อนรัน

หมายเหตุ
  รันครั้งแรกจะดาวน์โหลดโมเดล MiniLM ถ้าเครื่องเคยรันงาน 6.5 มาแล้วจะใช้ไฟล์เดิมได้ทันที
  มุมขวาบนของเว็บต้องขึ้นว่า โมเดลค้นหาพร้อม และ gemini-3.5-flash-lite ก่อนนำเสนอ
  เว็บใช้ gemini-3.5-flash-lite เป็นค่าเริ่มต้น เพราะวัดบนเครื่องทีมวันที่ 13 พ.ย. ตอบสำเร็จ 4 จาก 4 ข้อ
  ใช้เวลา 1.5 ถึง 3.6 วินาที ส่วน gemini-3.8-flash ที่ใช้ใน Colab ตอบไม่สำเร็จเลยในวันเดียวกัน
  ก่อนขึ้นนำเสนอ รัน python3 S02-G07_modelcheck.py อีกรอบ ถ้ารุ่นนี้ล้ม ให้ใช้รุ่นสำรอง
       export GEMINI_MODEL="gemini-flash-lite-latest"
  ถ้าเปลี่ยนรุ่น Gemini ให้พิมพ์ export GEMINI_MODEL="ชื่อรุ่น" ก่อนรัน
  ต้องต่ออินเทอร์เน็ตตอนใช้ Gemini และตอนเปิดลิงก์เอกสารในหน้าแหล่งข้อมูล
